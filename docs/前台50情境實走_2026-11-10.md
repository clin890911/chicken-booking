# 前台 50 情境實走計畫（2026-11-10 夜間）

目的：以「正在忙的店員」視角，實際照操作流程走一遍後台，找出會卡住（多按一下、找不到、要想一下、按錯、沒回饋、無法復原）的地方，直接修、補測試。

評分口徑（每個情境都記）：
- **步數**：從看到客人到完成，要點幾下（含捲動、切頁、確認框）。
- **卡點等級**：🔴 做不到／資料錯 ｜ 🟠 要繞路或多 3 下以上 ｜ 🟡 要想一下／沒回饋 ｜ 🟢 順。
- **可復原**：做錯能不能一下倒回。
- **多裝置**：另一台 iPad 幾秒內看得到。

環境：worktree `night-50`（origin/main 559b87b），Playwright e2e 攔截所有 `admin*`/`guest*` 端點，不碰正式資料。實走方式＝每個情境寫成（或沿用）一條 e2e，跑出步數與結果；UI 細節再用 chrome-devtools 截圖對照。

| A5 | 帶錯桌（按到隔壁） | 入座後 5 秒內復原 | 一下復原、桌回空桌、沒發通知 |
| A6 | 2F 帶位（1F 滿） | 切樓層 → 選桌 | 樓層鈕一下切、人數狀態保留 |

| A8 | 沿用上一組（同一家人分兩桌） | 帶完第一桌 → 沿用 → 選第二桌 | 不重填人數電話；不外洩上一組 notes 以外欄位 |
